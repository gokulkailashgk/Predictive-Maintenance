# Predictive Maintenance

## 👤 Author

**Gokul Kailash**

## 📌 Introduction

This project focuses on predicting aircraft engine failures using machine learning.

## 🎯 Problem Statement

Failure prediction is an important area of predictive maintenance.

### Objectives

- Predict engine failure
- Estimate Remaining Useful Life (RUL)
- Support maintenance planning

## 📊 Dataset

The project uses simulated aircraft engine data.

### Dataset Files

- `PM_train.txt`
- `PM_test.txt`
- `PM_truth.txt`

## 🧠 Machine Learning Approach

### 1. Regression Modeling

Predicts the remaining cycles before engine failure.

### 2. Binary Classification

Predicts whether an engine will fail within a specific cycle window.

### 3. Multiclass Classification

Predicts the expected failure period.
